## Soal 2 — Memahami `self` (20 poin)

a. Apa fungsi `self` di dalam method Python? *(10 poin)*

b. Apa yang terjadi jika parameter `self` **dihilangkan** dari sebuah instance method, lalu method tersebut dipanggil lewat object? Tuliskan pesan error yang muncul. *(10 poin)*

**Jawaban:**
a. Fungsi self
self adalah referensi ke object yang sedang memanggil method. Dengan self, kita dapat mengakses attribute dan method milik object tersebut.

Contoh:
```python
class Mahasiswa:
    def __init__(self, nama):
        self.nama = nama

    def sapa(self):
        print(f"Halo, saya {self.nama}")
Saat m1.sapa() dipanggil, self merujuk pada object m1.
```

b. Jika self dihilangkan
Jika method ditulis tanpa parameter self lalu dipanggil melalui object, akan muncul error:

TypeError: info() takes 0 positional arguments but 1 was given
Hal itu terjadi karena Python otomatis mengirimkan object sebagai argumen pertama ketika instance method dipanggil.

## Soal 3 — Prediksi Output (20 poin)

Perhatikan kode berikut:

```python
class Mahasiswa:
    def __init__(self, nama, nim):
        self.nama = nama
        self.nim = nim

    def sapa(self):
        print(f"Halo, saya {self.nama} ({self.nim})")


m1 = Mahasiswa("Budi", "SI-101")
m2 = Mahasiswa("Ani", "SI-102")

m1.sapa()
m2.sapa()
```

Tuliskan **output** yang muncul saat kode dijalankan, dan jelaskan **mengapa `m1` dan `m2` menghasilkan output yang berbeda** padahal keduanya dibuat dari class yang sama.

**Jawaban:**
Outputnya adalah:

Halo, saya Budi (SI-101)
Halo, saya Ani (SI-102)
`m1` dan `m2` dibuat dari class yang sama, yaitu `Mahasiswa`, tetapi keduanya merupakan object yang berbeda. Masing-masing object memiliki nilai attribute sendiri:

`m1.nama` bernilai `"Budi"` dan `m1.nim` bernilai `"SI-101"`.

`m2.nama` bernilai `"Ani"` dan `m2.nim` bernilai `"SI-102"`.

Ketika method `sapa()` dipanggil, `self` mengacu pada object yang memanggil method tersebut. Karena itu, `m1.sapa()` menampilkan data Budi, sedangkan `m2.sapa()` menampilkan data Ani.

## Soal 4 — Cari & Perbaiki Error (20 poin)

Kode berikut **memiliki 2 kesalahan**. Temukan, sebutkan, dan perbaiki:

```python
class Buku:
    def __init__(self, judul):
        self.judul = judul

    def info():
        print(f"Judul: {judul}")


b = Buku("Pemrograman Python")
b.info()
```

**Kesalahan 1:** &nbsp;
Method info() tidak memiliki parameter self.

Kode yang salah:

```python
def info():
```

**Kesalahan 2:** &nbsp;
Variabel judul harus diakses melalui self.judul, karena judul merupakan attribute milik object.

Kode yang salah:

```python
print(f"Judul: {judul}")
```

**Kode yang sudah diperbaiki:**
Kode yang sudah diperbaiki
```python
class Buku:
    def __init__(self, judul):
        self.judul = judul

    def info(self):
        print(f"Judul: {self.judul}")


b = Buku("Pemrograman Python")
b.info()
```
Output:

Judul: Pemrograman Python

## Soal 5 — Constructor & Class Attribute (20 poin)

Perhatikan kode berikut:

```python
class Produk:
    total_produk = 0

    def __init__(self, nama):
        self.nama = nama
        Produk.total_produk += 1


a = Produk("Laptop")
b = Produk("Mouse")
c = Produk("Keyboard")

print(Produk.total_produk)
print(a.nama)
```

a. Kapan method `__init__()` dipanggil? Apa fungsinya? *(10 poin)*

b. Tuliskan **output** kedua perintah `print` di atas, dan jelaskan perbedaan `total_produk` (class attribute) dengan `nama` (instance attribute). *(10 poin)*

**Jawaban:**
a. Fungsi `__init__()`
Method `__init__()` disebut constructor. Method ini otomatis dipanggil ketika object baru dibuat.

Contohnya:

```python
a = Produk("Laptop")
#Saat baris tersebut dijalankan, Python otomatis memanggil:

__init__(self, "Laptop")
```
Fungsi `__init__()` adalah memberikan nilai awal pada attribute object, seperti self.nama.

b. Output dan penjelasan
Outputnya:

3
Laptop

Penjelasan:

`total_produk` adalah class attribute, yaitu attribute yang dimiliki bersama oleh class Produk. Nilainya bertambah setiap kali object baru dibuat.

`a.nama` adalah instance attribute, yaitu attribute yang hanya dimiliki oleh object tertentu. Pada object `a`, nilainya adalah `"Laptop"`.

Tiga object dibuat:

```python
a = Produk("Laptop")
b = Produk("Mouse")
c = Produk("Keyboard")
```

Karena itu, nilai `Produk.total_produk` menjadi `3`. Sementara itu, `a.nama` hanya menunjukkan nama milik object `a`, yaitu `"Laptop"`
