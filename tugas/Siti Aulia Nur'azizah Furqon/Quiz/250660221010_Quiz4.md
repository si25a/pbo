## Soal 1 — Superclass dan Subclass

Jelaskan perbedaan superclass dan subclass. Berikan satu contoh hierarki class dari Sistem Informasi Perpustakaan.

**Jawaban:**
* **Superclass (Parent Class / Class Induk):** Class yang mendefinisikan attribute dan method umum yang akan diwariskan ke class lain.
* **Subclass (Child Class / Class Turunan):** Class yang mewarisi (*inherit*) attribute dan method dari superclass, serta dapat memiliki attribute dan method spesifiknya sendiri.

Contoh Hierarki Class di Sistem Informasi Perpustakaan:

* Superclass: `Buku` (memiliki attribute `judul`, `penulis`, `isbn`)
* Subclass: `BukuCetak` (tambah attribute `jumlah_halaman`) dan `BukuDigital` (tambah attribute `ukuran_file`, `format_file`)

```
          [ Buku ] (Superclass)
             /  \
            /    \
  [ BukuCetak ]  [ BukuDigital ] (Subclass)
```

## Soal 2 — Fungsi `super().__init__()`

Jelaskan fungsi `super().__init__()` pada constructor subclass. Mengapa pemanggilan tersebut diperlukan?

**Jawaban:**
Fungsi `super().__init__()` digunakan untuk memanggil constructor dari superclass (*parent class*) dari dalam constructor subclass (*child class*).

**Alasan Mengapa Pemanggilan Tersebut Diperlukan:**
1. **Menginisialisasi Attribute Induk:** Memastikan bahwa attribute-attribute umum yang didefinisikan pada superclass diinisialisasi dengan benar saat objek subclass dibuat.
2. **Mencegah Duplikasi Kode (DRY - Don't Repeat Yourself):** Subclass tidak perlu menulis ulang logika inisialisasi yang sudah ada di superclass.
3. **Memelihara Konsistensi:** Menjamin bahwa subclass mewarisi status dasar yang sah dari parent class-nya sebelum menambahkan attribute khusus milik subclass.

## Soal 3 — Overriding

Jelaskan overriding dan berikan contoh penerapannya pada method yang diwarisi dari superclass.

**Jawaban:**
**Method Overriding** adalah kemampuan subclass untuk menyediakan implementasi spesifik dari sebuah method yang sudah didefinisikan di superclass-nya. Saat method tersebut dipanggil melalui objek subclass, versi method di subclass-lah yang akan dieksekusi, bukan versi di superclass.

Contoh Penerapan:

```python
class Anggota:

    def hitung_denda(self, hari_terlambat):
        return hari_terlambat * 1000  # Tarif umum denda


class MahasiswaDua(Anggota):
    # Overriding method hitung_denda untuk anggota tipe Mahasiswa
    def hitung_denda(self, hari_terlambat):
        return hari_terlambat * 500  # Mahasiswa dapat diskon tarif denda
```

## Soal 4 — Hubungan is-a

Mengapa inheritance sebaiknya digunakan ketika terdapat hubungan **is-a**? Jelaskan alasan teknisnya.

**Jawaban:**
Inheritance sebaiknya hanya digunakan ketika ada hubungan **is-a** (sebuah subclass *merupakan bagian dari/jenis spesifik* dari superclass, misalnya: *Mahasiswa is-a Pengguna* atau *BukuDigital is-a Buku*).

**Alasan Teknis:**
1. **Prinsip Substitusi Liskov (Liskov Substitution Principle - LSP):** Objek subclass harus dapat menggantikan objek superclass tanpa merusak perilaku sistem. Jika digunakan pada hubungan yang salah (bukan *is-a*), subclass akan mewarisi method yang tidak relevan atau merusak logika program.
2. **Abstraksi dan Struktur Kode yang Benar:** Hubungan *is-a* menjamin terjadinya pemanfaatan kembali kode (*code reuse*) secara logis. Jika hubungannya adalah *has-a* (memiliki), pendekatan yang benar adalah **Komposisi/Agregasi**, bukan *Inheritance*.

## Soal 5 — Prediksi Output (20 poin)

Perhatikan kode berikut:

```python
class Pengguna:

    def tampilkan_peran(self):
        return "Pengguna"


class Mahasiswa(Pengguna):

    def tampilkan_peran(self):
        return "Mahasiswa"
```

Tuliskan output dari `Mahasiswa().tampilkan_peran()` dan jelaskan konsep OOP yang ditunjukkan.

**Jawaban:**
Outputnya adalah:

```
Mahasiswa
```

**Konsep OOP yang Ditunjukkan:**
Kode di atas menunjukkan konsep **Method Overriding** (dan *Polymorphism*). Subclass `Mahasiswa` mendefinisikan ulang method `tampilkan_peran()` yang diwarisi dari superclass `Pengguna`. Ketika `Mahasiswa().tampilkan_peran()` dipanggil, Python mengeksekusi versi method yang ada pada class `Mahasiswa` (mengisi/menimpa method milik induknya), sehingga yang dikembalikan adalah string `"Mahasiswa"`.
