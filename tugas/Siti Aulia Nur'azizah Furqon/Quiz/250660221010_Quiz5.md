## Soal 1 — Konsep Polymorphism

Jelaskan pengertian polymorphism dalam OOP dan berikan satu contoh method yang menghasilkan perilaku berbeda pada class yang berbeda.

**Jawaban:**
**Polymorphism** (secara harfiah: "banyak bentuk") adalah konsep dalam OOP yang memungkinkan objek-objek dari class yang berbeda diproses melalui antarmuka (*interface*) yang sama, di mana setiap objek dapat merespons pemanggilan method yang sama dengan perilaku/hasil yang spesifik sesuai bentuk class-nya masing-masing.

Contoh method yang menghasilkan perilaku berbeda pada class berbeda:
Method `hitung_denda()` pada sistem perpustakaan:
* Pada class `Mahasiswa`, `hitung_denda()` mengembalikan denda Rp500/hari.
* Pada class `Dosen`, `hitung_denda()` mengembalikan denda Rp0/hari (bebas denda).

## Soal 2 — Overriding dan Polymorphism

Jelaskan hubungan antara overriding dan polymorphism. Mengapa overriding menjadi dasar perilaku polimorfik pada Python?

**Jawaban:**
**Hubungan:**
Method *overriding* adalah mekanisme teknis di mana subclass mendefinisikan ulang method yang diwarisi dari superclass. Poin pentingnya, *overriding* menyediakan mekanisme bagi *subclass* untuk mengubah perilaku method bawaan induknya.

**Mengapa Overriding Menjadi Dasar Perilaku Polimorfik:**
Dengan *overriding*, objek-objek turunan yang dipanggil melalui antarmuka/method yang sama dapat memberikan respons yang unik dan berbeda-beda. Tanpa *overriding*, semua *subclass* hanya akan mengeksekusi perilaku yang persis sama milik *superclass*, sehingga sifat polimorfis (berbeda-beda bentuk) tidak akan pernah terwujud.

## Soal 3 — Prediksi Output (20 poin)

Perhatikan kode berikut:

```
class Pengguna:
    def tampilkan_peran(self):
        return "Pengguna sistem"

class Mahasiswa(Pengguna):
    def tampilkan_peran(self):
        return "Mahasiswa"

class Dosen(Pengguna):
    def tampilkan_peran(self):
        return "Dosen"

for data in [Mahasiswa(), Dosen()]:
    print(data.tampilkan_peran())

```

Tuliskan **output** dari program tersebut dan jelaskan **konsep OOP yang ditunjukkan**.

**Jawaban:**
Outputnya adalah:

```
Mahasiswa
Dosen

```

**Konsep OOP yang Ditunjukkan:**
Program tersebut menunjukkan **Polymorphism berbasis Inheritance (Subtype Polymorphism / Method Overriding)**. Loop menelusuri daftar objek yang merupakan instance dari class berbeda (`Mahasiswa` dan `Dosen`). Ketika `data.tampilkan_peran()` dipanggil, Python mengeksekusi versi method yang sudah di-*override* oleh masing-masing objek, sehingga menghasilkan output yang berbeda untuk tiap elemen dalam daftar tanpa perlu pengecekan tipe objek.

## Soal 4 — Duck Typing (20 poin)

Perhatikan kode berikut:

```
class Mahasiswa:
    def ringkasan(self):
        return "Mahasiswa — Budi"

class Dosen:
    def ringkasan(self):
        return "Dosen — Sari"

def tampilkan(data):
    print(data.ringkasan())

tampilkan(Mahasiswa())
tampilkan(Dosen())

```

Jelaskan mengapa fungsi `tampilkan()` dapat menerima kedua object meskipun `Mahasiswa` dan `Dosen` tidak memiliki hubungan inheritance.

**Jawaban:**
Fungsi `tampilkan()` dapat menerima kedua objek tersebut karena Python menerapkan konsep **Duck Typing** (*"If it walks like a duck and quacks like a duck, it's a duck"*).

Dalam Duck Typing, Python tidak peduli pada *tipe* atau *hierarki inheritance* dari objek yang dikirim ke fungsi `tampilkan(data)`. Python hanya peduli apakah objek tersebut memiliki **method/perilaku `ringkasan()`** yang diminta. Karena class `Mahasiswa` dan `Dosen` sama-sama mengimplementasikan method `ringkasan()`, keduanya valid untuk diproses oleh fungsi `tampilkan()`.

## Soal 5 — Merancang Fungsi Polimorfik (20 poin)

Tuliskan fungsi `tampilkan_semua(daftar)` yang menerima daftar object beragam dan memanggil method `ringkasan()` pada setiap object tanpa memeriksa tipe. Jelaskan apa yang terjadi jika sebuah object tidak memiliki method `ringkasan()`.

**Jawaban:**

**Kode Fungsi `tampilkan_semua(daftar)`:**

```
def tampilkan_semua(daftar):
    for obj in daftar:
        print(obj.ringkasan())

```

**Apa yang terjadi jika sebuah object tidak memiliki method `ringkasan()`:**
Jika salah satu objek di dalam `daftar` tidak memiliki method `ringkasan()`, Python akan menghentikan eksekusi program saat memproses objek tersebut dan melemparkan kesalahan (*exception*) berupa:

```
AttributeError: 'NamaClass' object has no attribute 'ringkasan'

```

Hal ini terjadi karena Python mencoba mengeksekusi method `ringkasan()` pada runtime, tetapi atribut/method tersebut tidak ditemukan pada definisi class objek yang bersangkutan.
