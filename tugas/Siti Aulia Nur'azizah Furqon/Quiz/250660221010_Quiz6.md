## Soal 1 — Konsep Abstraction

Jelaskan pengertian abstraction dalam OOP dan berikan satu contoh antarmuka yang menyembunyikan detail implementasi.

**Jawaban:**
**Abstraction (Abstraksi)** adalah konsep dalam OOP yang fokus pada penyampaian fitur-fitur penting dari suatu objek tanpa perlu menampilkan detail implementasi yang rumit di baliknya. Abstraksi menyembunyikan kompleksitas eksekusi dan hanya menyediakan antarmuka (*interface*) sederhana kepada pengguna.

**Contoh Antarmuka:**
Method `bayar()` pada sistem pembayaran digital. Pengguna atau pemanggil fungsi hanya perlu mengetahui bahwa memanggil `bayar(jumlah)` akan memproses transaksi. Pengguna tidak perlu tahu detail rumit di balik layar seperti koneksi enkripsi ke server bank, proses otentikasi API, pemotongan saldo di database, atau verifikasi token keamanan.

## Soal 2 — Abstract Class dan Abstract Method

Jelaskan perbedaan abstract class dan abstract method. Mengapa abstract class tidak dapat diinstansiasi langsung?

**Jawaban:**

* **Abstract Class:** Class yang diwarisi dari `ABC` (*Abstract Base Class*) yang dirancang sebagai cetak biru (*blueprint*) dasar untuk class turunan dan tidak dimaksudkan untuk dibuat menjadi objek langsung. Class ini biasanya memuat satu atau lebih *abstract method*.

* **Abstract Method:** Method yang dideklarasikan dengan decorator `@abstractmethod` di dalam *abstract class* yang **hanya memiliki nama/header tanpa implementasi** (hanya berisi `pass`), sehingga wajib di-override dan diimplementasikan oleh setiap subclass.

**Mengapa Abstract Class Tidak Dapat Diinstansiasi Langsung:**
Abstract class tidak dapat diinstansiasi (`Objek = AbstractClass()`) karena class tersebut belum lengkap secara struktur (memiliki metode abstrak yang belum ada kodenya/implementasinya). Jika diizinkan membuat objek langsung, pemanggilan method tersebut akan bingung karena tidak ada kode yang bisa dieksekusi.

## Soal 3 — Prediksi Output (20 poin)

Perhatikan kode berikut:

```
from abc import ABC, abstractmethod


class Pengguna(ABC):

    def __init__(self, nama):
        self.nama = nama

    @abstractmethod
    def tampilkan_peran(self):
        pass


class Mahasiswa(Pengguna):

    def tampilkan_peran(self):
        return "Mahasiswa"


print(Mahasiswa("Budi").tampilkan_peran())

```

Tuliskan **output** dari program tersebut dan jelaskan **peran `@abstractmethod`**.

**Jawaban:**
Outputnya adalah:

```
Mahasiswa

```

**Peran `@abstractmethod`:**
Decorator `@abstractmethod` berfungsi mendandai method `tampilkan_peran()` sebagai **kontrak wajib**. Decorator ini memaksakan bahwa setiap *subclass* (seperti `Mahasiswa`) yang mewarisi class `Pengguna` **wajib** mendefinisikan ulang (*override*) dan mengimplementasikan isi dari method `tampilkan_peran()`. Jika subclass tidak mengimplementasikannya, instansiasi objek dari subclass tersebut akan ditolak oleh Python.

## Soal 4 — Error pada Abstract Class (20 poin)

Perhatikan kode berikut:

```
from abc import ABC, abstractmethod


class Pengguna(ABC):

    @abstractmethod
    def tampilkan_peran(self):
        pass


class Mahasiswa(Pengguna):
    pass


mahasiswa = Mahasiswa()

```

Apa yang terjadi ketika `Mahasiswa()` dijalankan? Jelaskan **alasan teknisnya**.

**Jawaban:**
Ketika `Mahasiswa()` dijalankan, program akan **berhenti dan melempar exception/error**:

```
TypeError: Can't instantiate abstract class Mahasiswa with abstract method tampilkan_peran

```

**Alasan Teknis:**
Class `Mahasiswa` mewarisi class `Pengguna` yang memiliki *abstract method* `@abstractmethod def tampilkan_peran(self)`. Karena class `Mahasiswa` tidak melakukan *override* atau tidak mengimplementasikan kode untuk method `tampilkan_peran()` (hanya berisi `pass`), maka `Mahasiswa` secara otomatis dianggap masih sebagai *abstract class*. Python secara tegas melarang pembuatan objek/instansiasi dari class yang masih berstatus abstrak.

## Soal 5 — Merancang Abstract Class (20 poin)

Tuliskan abstract class `Transaksi` dengan abstract method `proses()`, lalu buat subclass `TransaksiTunai` yang mengimplementasikan method tersebut. Jelaskan manfaat kontrak perilaku pada rancangan tersebut.

**Jawaban:**

**Kode Program:**

```
from abc import ABC, abstractmethod


class Transaksi(ABC):

    def __init__(self, jumlah):
        self.jumlah = jumlah

    @abstractmethod
    def proses(self):
        pass


class TransaksiTunai(Transaksi):

    def proses(self):
        print(f"Memproses pembayaran tunai sebesar Rp{self.jumlah}")


# Contoh penggunaan:
t = TransaksiTunai(50000)
t.proses()

```

**Manfaat Kontrak Perilaku (Behavioral Contract):**

1. **Konsistensi Struktur Kode:** Memastikan semua jenis transaksi (baik `TransaksiTunai`, `TransaksiTransfer`, maupun `TransaksiEWallet`) dijamin memiliki method bernama `proses()`.

2. **Memudahkan Pengkodingan Tim (Standardisasi):** Developer lain yang ingin membuat jenis transaksi baru cukup fokus mengisi isi method `proses()` tanpa ragu menetapkan nama method baru yang membingungkan.

3. **Mendukung Polymorphism:** Sistem dapat menjalankan `transaksi.proses()` untuk objek transaksi apa pun secara umum tanpa khawatir terjadi kesalahan akibat method yang tidak ditemukan.
