## Soal 1 — Class dan Object

Jelaskan perbedaan **class** dan **object**. Berikan contoh class `MataKuliah` dan dua object yang dibuat dari class tersebut.

**Jawaban:**
**Class** adalah rancangan atau cetak biru (*blueprint*) yang mendefinisikan *attribute* dan *method* yang akan dimiliki oleh suatu object. Sedangkan **Object** adalah instansiasi nyata atau wujud konkret yang dibuat dari class tersebut.

Contoh pada class `MataKuliah`:

```python
class MataKuliah:
    def __init__(self, nama, sks):

# Dua object yang dibuat dari class MataKuliah:
mk1 = MataKuliah("Pemrograman Berorientasi Objek", 3)
mk2 = MataKuliah("Struktur Data", 4)
```

## Soal 2 — Attribute dan Method

Jelaskan perbedaan **attribute** dan **method**. Berikan satu contoh masing-masing pada class `Mahasiswa`.

**Jawaban:**
**Attribute** adalah variabel di dalam class yang digunakan untuk menyimpan data, status, atau karakteristik dari sebuah object. Sedangkan **Method** adalah fungsi di dalam class yang mendefinisikan perilaku, aksi, atau tindakan yang dapat dilakukan oleh object tersebut.

Contoh pada class `Mahasiswa`:

```python
class Mahasiswa:
    def __init__(self, nama):
        self.nama = nama  # Attribute: menyimpan data nama mahasiswa

    def belajar(self):  # Method: perilaku/aksi mahasiswa
        print(f"{self.nama} sedang belajar.")
```

## Soal 3 — Prediksi Output

Perhatikan kode berikut:

```python
class Buku:
    def __init__(self, judul):
        self.judul = judul

    def info(self):
        print(self.judul)


buku1 = Buku("Python Dasar")
buku2 = Buku("OOP dengan Python")
buku1.info()
buku2.info()
```

Tuliskan **output** dan jelaskan **mengapa kedua object menghasilkan judul berbeda**.

**Jawaban:**
Outputnya adalah:

```text
Python Dasar
OOP dengan Python
```

**Penjelasan:**
`buku1` dan `buku2` merupakan dua object yang berbeda (independen) meskipun keduanya dibuat dari class yang sama (`Buku`). Masing-masing object menyimpan nilai pada *instance attribute* `self.judul`-nya sendiri saat proses instansiasi (`"Python Dasar"` untuk `buku1` dan `"OOP dengan Python"` untuk `buku2`). Ketika method `info()` dipanggil, `self` bertindak sebagai pemanggil yang merujuk pada instance masing-masing, sehingga `buku1.info()` mencetak judul milik `buku1` dan `buku2.info()` mencetak judul milik `buku2`.

```python
        # Lengkapi

        # Lengkapi
```

**Jawaban:**

Kode yang sudah dilengkapi:

```python
class Mahasiswa:
    def __init__(self, nama):
        self.nama = nama
        self.sks = 0  # Inisialisasi awal nilai SKS

    def tambah_sks(self, jumlah):
        self.sks += jumlah

    def info(self):
        print(f"Nama: {self.nama}, Total SKS: {self.sks}")


# Contoh penggunaan/pengujian:
m = Mahasiswa("Budi")
m.tambah_sks(3)
m.info()
```

```text
Nama: Budi, Total SKS: 3
```

## Soal 5 — Interaksi Object

Jelaskan **alur yang terjadi** ketika `anggota.pinjam_buku(buku)` dipanggil pada sistem perpustakaan. Sebutkan **method pada object `Anggota` dan object `Buku` yang terlibat**.

**Jawaban:**

**Alur yang terjadi:**
1. Object `anggota` (dari class `Anggota`) memanggil method `pinjam_buku(buku)` dengan menerima argumen berupa object `buku` (dari class `Buku`).
2. Di dalam method `pinjam_buku()`, object `anggota` berinteraksi dengan object `buku` dengan memanggil method pengecekan status pada object `buku` (misalnya `buku.cek_ketersediaan()`) untuk mengecek apakah buku tersebut bisa dipinjam.
3. Jika buku tersedia, object `anggota` akan menyimpan referensi `buku` ke dalam daftar/list pinjamannya dan memanggil method pengubah status pada object `buku` (misalnya `buku.set_status("dipinjam")`) untuk mengubah status buku menjadi tidak tersedia.

**Method yang terlibat:**
- **Pada object `Anggota`:** Method `pinjam_buku(buku)` (sebagai pengatur alur peminjaman).
- **Pada object `Buku`:** Method seperti `cek_ketersediaan()` (untuk membaca status buku) dan `set_status()` / `pinjam()` (untuk memperbarui status ketersediaan buku).
